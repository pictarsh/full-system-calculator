## Description
The FullCalculator project features a full-featured calculator application with a clean, circular button layout that evaluates mathematical expressions dynamically using JavaScriptCore.

## SwiftUI API Reference
### Layout
- **VStack()** : Stacks elements vertically (top to bottom).
- **HStack()** : Stacks elements horizontally (left to right).

### Content
- **Text()** : Displays text on the screen.
- **Button()** : Triggers an action when tapped by the user.

### Modifiers
- **.font()** : Sets typography sizes and hierarchy styles (such as large custom system sizes).
- **.padding()** : Adds spacing around or inside elements.
- **.frame()** : Sets explicit width, height, and alignment bounds for the display screen and circular keypads.
- **.foregroundStyle()** : Applies colors to text and graphics based on button function.
- **.fontWeight()** : Sets text weight to emphasize button symbols and input numbers.
- **.background()** : Applies background colors behind elements.
- **.clipShape()** : Masks views into specific shapes, such as a Circle for keypads.
- **.disabled()** : Controls the interactive state of operator and action buttons based on input availability.
